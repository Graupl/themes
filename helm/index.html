Your markup. Your theme.

Helm uses all thirteen Graupl core components, plus its buttons, links, forms, tables, typography, and layout utilities. Icons and navigation shelf are not included.

Keep theme.css after Graupl's stylesheet. Existing --graupl-* properties do most of the work on :root. Scoped properties refine component variants. A few decorative rules add accents without changing the markup. The only custom script controls appearance, not components.

Remove the theme stylesheet to use base Graupl with the same markup and interactions.
