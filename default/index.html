The base framework.

This example uses all thirteen Graupl core components, plus its buttons, links, forms, tables, typography, and layout utilities. Icons and navigation shelf are not included.

The only stylesheet is graupl.css, pinned to the current 1.x source commit. This page does not set --graupl-* properties on :root or anywhere else. The only custom script controls appearance, not components.

Components use Graupl's generators and options. Accessible Menu provides the navigation behavior. No custom CSS file is included.
