# Graupl Themes

A collection of small CSS themes for [Graupl](https://github.com/Graupl/graupl). Each theme has a `theme.css` stylesheet and an `index.html` preview.

## Use a theme

Load the theme's `theme.css` after the Graupl stylesheet. Start with the Graupl revision used by the theme's preview. Keep your existing Graupl markup and JavaScript. To restore Graupl's styles, remove the theme stylesheet.

To compare themes locally, serve this repository with a static file server and open the theme's preview. The previews load Graupl from a CDN.

## Contribute

Read the [contribution guidelines](.github/CONTRIBUTING.md) and the [Graupl theme skill](skills/graupl-theme/SKILL.md) before adding or editing a theme. Use the [theme issue tracker](https://github.com/Graupl/themes/issues) to report bugs or suggest changes.
