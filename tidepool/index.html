Your markup. Your theme.

Tidepool uses all thirteen Graupl core components, plus its buttons, links, forms, tables, typography, and layout utilities. Icons and navigation shelf are not included.

Keep theme.css after Graupl's stylesheet. Most declarations in the theme set an existing --graupl-* property. Most declarations are on :root. Scoped properties customize buttons and expanded accordion headers. An empty decorative wave follows the introduction. The only custom script controls appearance, not components.

Remove the theme stylesheet to use base Graupl with the same markup and interactions.
