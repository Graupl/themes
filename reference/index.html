An independent Graupl theme.

Reference uses all thirteen Graupl core components, plus its buttons, links, forms, tables, typography, and layout utilities. Icons and navigation shelf are not included.

Keep theme.css after Graupl's stylesheet. Most declarations in the theme set an existing --graupl-* property. Most declarations are on :root. Scoped properties customize component variants. A static decorative underscore adds an MDN-inspired detail to the heading. The only custom script controls appearance, not components.

Inspired by MDN Web Docs, without its branding or assets. This is an independent example, not a Mozilla product. Remove the theme stylesheet to restore base Graupl styling.
