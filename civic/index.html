Your markup. Your theme.

Civic uses all thirteen Graupl core components, plus its buttons, links, forms, tables, typography, and layout utilities. Icons and navigation shelf are not included.

Keep theme.css after Graupl's stylesheet. Existing --graupl-* properties still define the theme, mostly on :root. Scoped styles and decorative pseudo-elements add component details. The only custom script controls appearance, not components.

Remove the theme stylesheet to use base Graupl with the same markup and interactions.
